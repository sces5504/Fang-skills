TOOLS / VIDEO COMPRESSION

壓小檔案，
保留你的原始影片。

先算大小，再交給 FFmpeg。

設定每支影片的目標大小，取得兩次編碼腳本。這裡只產生文字；檔案留在你的電腦，不會上傳或在瀏覽器內轉檔。

MP4 · H.264 · 本機執行

01 / SOURCE

來源影片

影片模式
＋選取或拖入影片

只讀取本機片長、尺寸與大小，不上傳檔案。

瀏覽器通常無法取得完整路徑。選檔後仍須填入實際路徑；檔名不是完整路徑。無法讀取影片資訊時可手動補上，或留空片長讓腳本偵測。

批次模式會讓每支影片各自壓到相同目標大小，不合併影片。

02 / SETTINGS

壓縮設定

執行平台

1 MB = 1,000,000 bytes；1 MiB = 1,048,576 bytes。

等比例、不放大來源；直式影片以短邊限制，輸出為偶數寬高。保留尺寸也會向下調整奇數像素。

相同位元率下，較慢的 preset 通常能保留更多細節，但需要更多時間。

未知音軌時先預留音訊空間；腳本會實測，有音軌才編碼 AAC，無音軌則把預算留給影片。AAC 輸出為雙聲道。

進階：大小安全餘裕

預設保留 3.2% 給容器與編碼誤差，只扣一次。不能保證每次精準低於限制；數值越高，可用畫質越少。

03 / RUN LOCALLY

你的壓縮腳本

先填來源路徑，再複製或下載腳本。片長留空時，執行前會自動偵測。

在自己的終端機執行

1. 準備 FFmpeg

先安裝含 libx264 的 FFmpeg 與 ffprobe，並加入 PATH。安裝方式見 FFmpeg 官方下載 ↗。

macOS 若已使用 Homebrew，可執行 brew install ffmpeg。Windows 可使用官方頁面連結的 Windows build，或自行確認套件管理器來源。

2. 下載並執行

macOS：在下載資料夾開啟終端機，執行 bash ./ff-tool.sh。也可將完整腳本貼到 zsh / bash。

相對路徑以執行時的工作資料夾為準。輸出資料夾必須已存在；既有檔案一律不覆寫。批次工作依序執行，各自有獨立暫存目錄。

3. 確認結果

腳本會顯示每支影片的實測片長、位元率、實際 bytes 與成功／失敗。超標的輸出仍會保留並標示；提高安全餘裕或降低目標，再換新輸出名稱重跑。

H.264、yuv420p、MP4 faststart；只處理第一影像與第一音軌，不保留其他軌道、章節與來源 metadata。原始影片保持原樣。

用 ffprobe 取得片長、解析度與音軌

已帶入目前路徑，可逐行複製執行。若路徑尚未填寫，先替換範例路徑。

估算方式與限制

可用總位元率 = 目標 bytes × (1 − 安全餘裕) × 8 ÷ 秒數；影片位元率再扣音訊預算，向下取整為十進位 kbps。下方顯示的估計大小是影像與音訊資料，不含實際容器開銷。腳本以 ffprobe 的實測片長與音軌為準，僅在無法取得有效片長時使用手動值。

低位元率、高動態內容或長片會明顯降低畫質，可改用 480p / 360p 或增加目標。檔案很短時，容器開銷占比會更高。macOS 以同磁碟的硬連結安全發布輸出；不支援硬連結的磁碟會安全失敗，不覆寫檔案。Windows 輸出以不覆寫的 Move 發布。
