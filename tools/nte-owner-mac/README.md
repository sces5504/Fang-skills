# nte-owner-mac

macOS（Apple Silicon）桌面小工具，自動遊玩 NTE「店長精選」的 1-1 關卡。以 ScreenCaptureKit 擷取畫面、OpenCV 比對模板，再用一般 Quartz 鍵鼠事件操作；沒有記憶體存取、注入、遊戲檔案修改、網路攔截或反作弊繞過。

- 每局做兩杯番茄汁後按 Esc 結算，領取或退出後回到清單，再開始下一局。
- 內建繁體中文介面的辨識預設，首次開啟自動載入，通常不需校準。支援 16:9／16:10；其他語言或 UI 縮放需重新校準。
- 遊戲不在前景、被其他視窗遮住或視窗被關閉時立即停止；黑畫面與轉場則等待，不會盲點。
- 只提供原始碼，沒有已簽章的安裝檔。需要 macOS 14+ 與 Apple Silicon 原生 Python 3.11。

自動操作可能違反遊戲服務條款，請自行評估帳號風險。工具的點擊與時間微量變化不是用來規避偵測，也不保證不被遊戲辨識。

## 使用

1. 建立 App，輸出在 `dist/NTEOwnerMac.app`：

```sh
PYTHON_BIN=python3.11 bash scripts/build_app.sh
```

2. 開啟 App。本機建置採 ad-hoc 簽章；若 macOS 擋下，到「隱私權與安全性」選「仍要開啟」，不要停用系統安全功能。
3. 按「授予螢幕錄製／輔助使用權限」並到系統設定開啟。每次重新建置後簽章都會改變，可能要重新授權。
4. 在遊戲中手動進入「店長精選」關卡清單，清單停在哪裡都可以。
5. 先按「只辨識，不操作」，5 秒內切回遊戲，確認記錄正常。此模式不送出鍵鼠事件。
6. 局數先設 **1**（0 為無限），按「開始刷關」，5 秒內切回遊戲。工具會自動鎖定前景的 NTE 視窗，通常不需選視窗。

停止方式：切回工具按停止、切到其他 App，或把滑鼠移到遊戲視窗左上角 10 點內。工具停止時不會替你暫停遊戲或補做結算。

## 流程

```text
清單 → 向上捲動找 1-1 → 點 1-1 → 確認右側標題 → 開始營業
營業 → 看到訂單就做（杯子 → 0.12 秒 → 材料包），最多兩杯 → Esc
結算 → 結果畫面點「領取」，或挑戰失敗畫面點「退出」→ 回清單
```

訂單預設全部視為番茄汁，只辨識氣泡，不比對飲料。遇到不同餐點導致挑戰失敗屬於預期結果，工具會按「退出」繼續；這類局目前仍計入結束時顯示的「兩單」統計。

單杯送出後 1 秒內沒有訂單消失，會提前結算重開。活力在清單或結果畫面辨識為 0 時停止；讀不到活力時不會開始或領取，逾時後停止。此功能只判斷歸零，不估算剩餘局數。

## 校準與設定

只有辨識不符時才展開「進階辨識校準（通常不需要）」，用「5 秒後擷取遊戲」或載入完整視窗截圖，再框選模板與操作點。「測試本張截圖辨識」可查看各項分數；降低門檻可能增加誤判，應優先換乾淨且具辨識性的模板。

設定存於 `~/Library/Application Support/NTEOwnerMac/profile.json`，模板在同目錄 `templates/`，兩者要一起備份。升級時只遷移已知的內建預設值，手動校準會保留。

介面上的「辨識門檻」（預設 0.90）用於清單、營業 HUD 等畫面；訂單氣泡和部分模板有各自的門檻，如 `order_marker_threshold`（0.84）。其他可調項目：`state_timeout`（預設值 20 秒，內建設定 40 秒）、`round_timeout`（150 秒）、`click_gap`（0.12 秒）、`click_jitter_points`、`time_jitter_seconds`。後兩者設為 0 可關閉微量變化。

## 隱私與檔案

正常畫面只留在記憶體，所有資料都不會上傳。`logs/` 存放操作記錄，並在錯誤、停止或長時間沒有訂單時保存診斷截圖，可能含 UID，分享前請自行遮蔽。「清除執行截圖」只刪除本工具命名的診斷截圖，不動文字記錄、校準或模板。

此資料夾不含完整遊戲截圖、UID 或個人校準，只有辨識所需的小型 UI 裁切；這些裁切的權利仍屬遊戲權利人。

## 維護

`engine.py` 是不碰系統的狀態機，`vision.py` 負責模板、訂單與活力辨識，`macos.py` 與 `capture.py` 處理擷取、輸入和前景檢查，`runner.py` 串接執行迴圈，`gui.py` 是介面與校準，`config.py` 負責設定驗證和遷移。

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m pytest -q
.venv/bin/python main.py
```

`python scripts/replay.py --profile <profile.json> <截圖>` 可離線檢查單張截圖，不會擷取或操作。

自動測試涵蓋狀態機、辨識、保護條件與設定遷移，但不啟動遊戲。工具已在作者的 Mac 上實際跑過主要流程；0.1.12 的「挑戰失敗 → 退出」只用真實截圖驗證過，尚未在遊戲中實跑。多螢幕、外接螢幕與其他解析度也未完整驗證。repo 的 CI 只檢查靜態工具，不會執行這裡的測試，修改後要在本機跑。

散布 App 時請另加 Developer ID 簽章與公證，並附上對應原始碼。
