## 範圍限制

這是既有截圖上的回放驗證，不是動態遊戲錄影，也不是實際完成一局。未知訂單的負例測試以合成影像與狀態機觀測值進行；未收到真實非番茄汁訂單截圖。左右顧客、未滿三星結算、真實活力 0、領取後可能出現的額外畫面，仍列於 README 實機清單。

沒有執行遊戲操作、沒有替使用者開啟系統權限、沒有部署 GitHub repo 或觸發遠端 CI。
